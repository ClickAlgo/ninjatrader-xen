NINJASCRIPT BASELINE
- Strategies inherit Strategy and use NinjaTrader.NinjaScript.Strategies.
- Indicators inherit Indicator and use NinjaTrader.NinjaScript.Indicators.
- Follow OnStateChange and OnBarUpdate lifecycle rules.
- Reserve State.SetDefaults for metadata, Calculate, strategy behaviour
  properties and default values for public inputs.
- Never call SetStopLoss, SetProfitTarget, SetTrailStop or SetParabolicStop
  from State.SetDefaults. For static managed protection, set the public input
  defaults in State.SetDefaults and call the Set method in State.Configure.
  For dynamic protection, call it from the appropriate runtime method before
  submitting the associated entry and reset it safely when flat.
- Add secondary data series only in State.Configure.
- Create indicators and data-dependent resources in State.DataLoaded.
- Guard CurrentBar or CurrentBars before barsAgo access.
- Use NinjaScriptProperty, Display and Range appropriately for public inputs.
- Keep the C# class name and source filename as a descriptive PascalCase identifier. In State.SetDefaults, set Name to a readable user-facing title with spaces between words. For example, class SmartMoneyStructure should use Name = "Smart Money Structure";.
- Include every using directive required by referenced types.
- Avoid look-ahead bias and unavailable-bar access.
- Prefer simple, readable and maintainable NinjaScript.
