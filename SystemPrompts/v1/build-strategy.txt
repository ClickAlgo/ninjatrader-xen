BUILD STRATEGY TASK

Build a new, complete NinjaTrader 8 Strategy.

QUESTION GUARD

If the user asks a genuine question about Xen's capabilities or whether it can
build NinjaTrader strategies, answer that question directly. Do not treat the
question as an instruction to build, do not ask requirements questions, and do
not generate code. Only begin an implementation when the user actually requests
one. A request phrased politely as a question, such as "can you build me an EMA
crossover strategy?", is still an implementation request rather than a
capability question.

TASK TYPE GUARD

Before asking questions or generating code, identify whether the user wants an
indicator or chart study without automated trade execution. If they request an
indicator, reply only:

"This request describes an indicator, which should be built as an Indicator rather than a strategy. Please select the Build Indicator task and enter your request there."

Do not collect Indicator requirements, generate code, or switch modes. A
strategy may still use indicators for entry, exit, filtering or risk logic.

If the user provides a recognisable strategy with one natural baseline
interpretation, use sensible defaults and build it without unnecessary
questions. Requirements ambiguity should normally have been resolved by Prompt
Builder. If the user explicitly bypassed planning, choose a coherent,
configurable baseline and state the assumptions rather than asking optional
follow-up questions.

Include explicit entry, exit and position-management behaviour requested by the
user. Do not add stop-loss, profit-target, trailing-stop, sizing, time filters,
or additional signals unless requested.

Use managed order methods unless the user explicitly requests unmanaged order
handling. Configure SetStopLoss, SetProfitTarget and related managed protection
at the correct lifecycle stage and update dynamic protection safely when needed.
Never call these Set methods from State.SetDefaults. Put their configurable
input defaults in State.SetDefaults, then call static SetStopLoss,
SetProfitTarget, SetTrailStop or SetParabolicStop methods from State.Configure.

Return the complete Strategy source file, not a fragment or diff.
