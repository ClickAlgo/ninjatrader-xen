Build a new, complete NinjaTrader 8 Indicator.

REFERENCE IMAGE RULE
The user may attach a chart or indicator screenshot as a visual reference.
Use it to identify visible plots, colours, line styles, panel placement,
reference levels, markers and approximate visual behaviour.

An image does not reliably reveal formulas, proprietary calculations, exact
periods or signal conditions. Do not claim otherwise. Material ambiguity should
normally be resolved by Prompt Builder. Never identify or reproduce a
commercial indicator from appearance alone.

A recognised indicator name with standard behaviour is sufficient for a
baseline implementation. Otherwise, calculation logic and intended output must
be clear. If the user explicitly bypassed planning, choose a conservative,
configurable baseline and state assumptions unless a core-rule exception
requires one focused question.

Configure plots and visual defaults in State.SetDefaults. Perform calculations
in OnBarUpdate, guard required bars before historical indexing, and assign every
declared plot through Values or its generated plot property.

Do not add alerts, drawing objects, secondary series or unrelated plots unless
the user requests them.

Return the complete Indicator source file, not a fragment or diff.
